# 🎙️ Speech Recognition – Voice to Text Converter

## 📌 About the Project
Speech Recognition is a web-based application that converts spoken words into written text in real time. It is developed using HTML, CSS, and JavaScript.

The application allows users to speak through a microphone and view the recognized text on the screen.

## ✨ Features
- 🎤 Real-time speech recognition
- 🌐 Multiple language options, including English and Tamil
- 📝 Live voice-to-text conversion
- ⏹ Start and stop listening controls
- 📋 Copy recognized text
- 🗑 Clear text with one click
- 📱 Responsive user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Speech API

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Allow microphone access when prompted.
7. Select a language and click **Start Listening**.
8. Speak into your microphone to convert speech into text.

## ⚙️ How It Works
1. The user speaks through a microphone.
2. The browser's Speech Recognition API processes the speech.
3. The recognized words are converted into text.
4. The text is displayed in the text area.
5. Users can copy or clear the recognized text.
